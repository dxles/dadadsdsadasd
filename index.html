YouTube API Anahtarı Nasıl Alınır?

  1. Google Cloud Console'a git.

    console.cloud.google.com adresine gir ve Google hesabınla giriş yap.

  2. Yeni bir proje oluştur.

    Üst menüden proje seçiciye tıkla → "Yeni Proje" → bir isim ver (örn. "cinla-app") → Oluştur.

  3. YouTube Data API v3'ü etkinleştir.

    Sol menüden "APIs & Services" → "Library" → arama kutusuna "YouTube Data API v3" yaz → aç → "Enable" butonuna bas.

  4. API anahtarı oluştur.

    "APIs & Services" → "Credentials" → üstten "Create Credentials" → "API key" seç. Anahtarın oluşacak ve ekranda görünecek.

  5. (Önerilir) Anahtarı kısıtla.

    Güvenlik için anahtarın üstüne tıkla → "API restrictions" kısmından sadece "YouTube Data API v3" ile sınırla. İstersen "Application restrictions" ile de siteni belirtebilirsin.

  6. Anahtarı kopyala ve buraya yapıştır.

    Oluşan AIza... ile başlayan anahtarı kopyala, soldaki "YouTube API Anahtarın" kutusuna yapıştır ve "Kaydet" tuşuna bas. Anahtar sadece kendi tarayıcında (localStorage) saklanır, hiçbir sunucuya gönderilmez.

Not: YouTube Data API v3'ün günlük ücretsiz kotası (quota) sınırlıdır. "Yenile" ve arama işlemleri bu kotayı kullanır; kota dolarsa anahtar bir sonraki gün otomatik olarak tekrar çalışır.
