YouTube API anahtarı nasıl alınır?

  1. Google Cloud Console'a git.

    console.cloud.google.com adresine gir ve Google hesabınla giriş yap.

  2. Yeni bir proje oluştur.

    Üst menüden proje seçiciye tıkla, "Yeni Proje"yi seç, bir isim ver (örn. "cinla-app") ve Oluştur'a bas.

  3. YouTube Data API v3'ü etkinleştir.

    Sol menüden "APIs & Services" ve "Library"yi aç, "YouTube Data API v3" yaz, sonucu aç ve "Enable"a bas.

  4. API anahtarı oluştur.

    "APIs & Services" altında "Credentials"a git, "Create Credentials" ve "API key"i seç. Anahtar ekranda görünür.

  5. Anahtarı kısıtla (önerilir).

    Anahtara tıkla, "API restrictions" bölümünden sadece "YouTube Data API v3"ü seç. İstersen "Application restrictions" ile siteni de belirtebilirsin.

  6. Anahtarı buraya yapıştır.

    AIza... ile başlayan anahtarı soldaki "YouTube API anahtarı" kutusuna yapıştırıp Kaydet'e bas. Anahtar sadece bu tarayıcıda (localStorage) saklanır, hiçbir sunucuya gönderilmez.

Not: YouTube Data API v3'ün günlük ücretsiz kotası sınırlıdır. Her arama 100 birim harcar ve günlük kota 10.000 birimdir, yani günde yaklaşık 100 arama. Spotify aktarımında her şarkı bir arama sayılır. Kota dolarsa ertesi gün yeniden çalışır.
